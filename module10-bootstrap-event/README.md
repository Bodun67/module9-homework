# IT Future — реєстрація та калькулятор квитків

Навчальний адаптивний сайт для реєстрації на IT-конференцію. Проєкт створено на HTML5, Bootstrap 5.3 через CDN, CSS і JavaScript.

## Функції

- Адаптивна сторінка події з меню та описом тем.
- Форма реєстрації перевіряє ім’я, email і кількість учасників; після успіху показує повідомлення.
- Калькулятор Standard/VIP квитків: 400/800 грн за квиток.
- Знижка 10% при купівлі 3–4 квитків, 20% — від 5 квитків.
- Промокод `EVENT50` зменшує суму ще на 50 грн після знижки за кількість.

## Запуск

Відкрий `index.html` у браузері. Інтернет потрібен для завантаження Bootstrap CDN. Реєстраційна форма демонстраційна та не надсилає дані на сервер.

## Приклад перевірки

3 VIP-квитки: 3 × 800 = 2 400 грн; знижка 10% = 240 грн; промокод `EVENT50` = 50 грн; до сплати — **2 110 грн**.
