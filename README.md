# Домашнє завдання — Модуль 9

## Завдання 1 — картка профілю

- task1.html — сторінка профілю Романіва Богдана.
- style.css — окремі стилі картки, відступи, тінь і hover-ефект.

## Завдання 2 — адаптивний каталог товарів

- task2.html і task2.css — магазин із шістьма товарами.
- CSS Grid: три картки на комп’ютері, дві на планшеті та одна на телефоні.
- Flexbox вирівнює вміст карток і притискає кнопки донизу.
- Ілюстрації товарів збережені в assets/.

## Як відкрити

Відкрий task1.html або task2.html у браузері. CSS та assets мають залишатися поруч із HTML-файлами.

Це навчальний статичний макет. Кнопки «Купити» не оформлюють замовлення; JavaScript і сервер не використовуються.
